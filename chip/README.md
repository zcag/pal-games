# Chip

Side-on golf in pal's panel: one hole for now, The Needle. ↑↓ aim, hold
Space for power, ←→ in the air for spin, R starts again, L changes the look
(Canyon, Alpine, Dusk, or the drawn Classic; kept, and synced).

The rules and the physics (planck.js, `game/vendor/`) are in `game/`; the
page is `surface/`. `scripts/solve.ts` finds the routes the tests replay.

The landscapes behind the flat looks are PWL's, CC0: `surface/art/README.md`.
