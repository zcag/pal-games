# Chip's landscapes

The layered landscapes behind the hole are PWL's, released under CC0 1.0
(public domain, no attribution required; credited here because it is due):

- `alpine-1.png` … `alpine-5.png`: "Seamless HD landscape in parts",
  https://opengameart.org/content/seamless-hd-landscape-in-parts
- `canyon-1.png` … `canyon-5.png`: "Seamless desert background in parts",
  https://opengameart.org/content/seamless-desert-background-in-parts

Layer 1 is the nearest. The canyon's were halved to 1920 by 1080 and set on
a full-height canvas, bottom aligned; all were requantised with pngquant.
The page recolours them for each look (`../looks.ts`); the flat sky layer
of each set is not shipped, the page paints its own.
